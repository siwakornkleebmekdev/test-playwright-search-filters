- **Priority:** `High` (Core Feature)
- **Test Type:** `E2E Functional Test (Desktop Only)`
- **Automation Status:** `Automated`

## 3. ขั้นตอนการทดสอบแบบละเอียด (Detailed Test Cases (BDD))

### TC-SEARCH-01: ค้นหาโพสต์ด้วยคำค้นหาสำเร็จ [Positive]
- **Given** Member เข้าสู่ระบบ
- **And** กดคลิ๊กไปที่หน้า "สำรวจเนื้อหา"
- **When** กรอกคำค้นหาว่า "ฟิสิกส์" ในช่องค้นหา
- **Then** ระบบแสดงรายการโพสต์ที่มีคำว่า "ฟิสิกส์" ในชื่อโพสต์ หรือเนื้อหา
- **And** ช่องค้นหาแสดงข้อความ "ฟิสิกส์" ตามที่ระบุ

### TC-SEARCH-02: คัดกรองโพสต์ตามระดับการศึกษาและหมวดหมู่วิชา [Positive]
- **Given** Member เข้าสู่ระบบ
- **And** กดคลิ๊กไปที่หน้า "สำรวจเนื้อหา"
- **When** เลือกตัวกรองระดับการศึกษาเป็น "มัธยมศึกษาตอนต้น" และเลือกหมวดหมู่วิชาเป็น "ภาษาอังกฤษ"
- **Then** ระบบแสดงเฉพาะรายการโพสต์ที่ตรงกับระดับการศึกษา "มัธยมศึกษาตอนต้น" และหมวดหมู่วิชา "ภาษาอังกฤษ"

### TC-SEARCH-03: การจัดเรียงผลลัพธ์การค้นหาตามวันที่ล่าสุด [Positive]
- **Given** Member เข้าสู่ระบบ
- **And** กดคลิ๊กไปที่หน้า "สำรวจเนื้อหา"
- **When** ระบบแสดงโพสต์ขึ้นมา
- **Then** ระบบจัดเรียงรายการโพสต์โดยแสดงโพสต์ที่มีวันที่สร้างล่าสุด (Newest) ไว้เป็นอันดับแรก และเรียงลำดับไปยังโพสต์ที่มีวันที่สร้างเก่าสุด (Oldest)

### TC-SEARCH-04: ค้นหาหรือเลือกตัวกรองแล้วไม่พบข้อมูล (Empty State) [Negative]
- **Given** Member เข้าสู่ระบบ
- **And** กดคลิ๊กไปที่หน้า "สำรวจเนื้อหา"
- **When** พิมพ์คำค้นหาเป็น "@" หรือเลือกตัวกรองที่ไม่มีโพสต์ตรงกับเงื่อนไข
- **Then** ระบบแสดงพื้นที่ Empty State พร้อมไอคอนแว่นขยาย และข้อความ "ไม่พบโพสต์ที่ตรงกับตัวกรอง"
- **And** ระบบแสดงลิงก์ "ล้างตัวกรองทั้งหมด"
- **When** กดลิงก์ "ล้างตัวกรองทั้งหมด"
- **Then** ระบบทำการล้างข้อความในช่องค้นหา และยกเลิกการเลือก Checkbox ตัวกรองทั้งหมด
- **And** ระบบกลับมาแสดงรายการโพสต์ทั้งหมดตามปกติ

### TC-SEARCH-05: ค้นหาร่วมกับการกรองหลายเงื่อนไขพร้อมกัน (Combined Search & Multi-Filter) [Positive]
- **Given** Member เข้าสู่ระบบ
- **And** กดคลิ๊กไปที่หน้า "สำรวจเนื้อหา"
- **When** กรอกคำค้นหาว่า "สรุปสูตรฟิสิกส์"
- **And** เลือกตัวกรองระดับการศึกษาเป็น "มัธยมศึกษาตอนปลาย"
- **Then** ระบบแสดงผลลัพธ์เฉพาะโพสต์ที่มีคำว่า "สรุปสูตรฟิสิกส์" ที่ตรงกับระดับ "มัธยมศึกษาตอนปลาย" พร้อมกันเท่านั้น
- **And** ผลลัพธ์ถูกจัดเรียงตามวันที่สร้างล่าสุดไปเก่าสุด

### TC-SEARCH-06: การสลับมุมมองการแสดงผลโพสต์ (Grid / List View Toggle) [Positive]
- **Given** Member เข้าสู่ระบบ
- **And** กดคลิ๊กไปที่หน้า "สำรวจเนื้อหา"
- **When** Member กดปุ่มสลับมุมมองเป็น "List View" (ไอคอนรายการด้านขวาบนของช่องค้นหา)
- **Then** ระบบเปลี่ยนรูปแบบการแสดงผลของโพสต์จากแบบการ์ด (Grid) เป็นแบบรายการเรียงลงมา (List) โดยที่ข้อมูลผลลัพธ์และตัวกรองที่เลือกไว้ยังคงเดิม

### TC-SEARCH-07: การยกเลิกตัวกรองบางรายการ (Uncheck Partial Filter) [Negative]
- **Given** Member เข้าสู่ระบบ
- **And** กดคลิ๊กไปที่หน้า "สำรวจเนื้อหา"
- **Then** ติ๊กเลือกระดับการศึกษาไว้ 2 รายการคือ "มัธยมศึกษาตอนต้น" และ "มัธยมศึกษาตอนปลาย"
- **When** Member ยกเลิกการเลือก (Uncheck) ระดับการศึกษา "มัธยมศึกษาตอนต้น" ออก
- **Then** ระบบทำการอัปเดตรายการทันทีโดยแสดงเฉพาะโพสต์ในระดับการศึกษา "มัธยมศึกษาตอนปลาย"
- **And** รายการโพสต์จะถูกจัดเรียงตามวันที่สร้างล่าสุดไปเก่าสุด

### TC-SEARCH-08: ยกเลิกตัวกรองระดับการศึกษาทั้งหมดแล้วไม่เหลือรายการที่เลือก [Positive]
- **Given** Member เข้าสู่ระบบ
- **And** กดคลิ๊กไปที่หน้า "สำรวจเนื้อหา"
- **Then** ติ๊กเลือกระดับการศึกษา "มัธยมศึกษาตอนต้น" อยู่
- **When** Member ยกเลิกการเลือก (Uncheck) ระดับการศึกษา "มัธยมศึกษาตอนต้น" ออก ทำให้ไม่มีระดับการศึกษาใดถูกเลือกเลย
- **Then** ระบบยกเลิกการกรองตามระดับชั้น และกลับมาแสดงผลรายการโพสต์ทั้งหมดตามเงื่อนไขอื่นที่เหลืออยู่ (หรือแสดงโพสต์ทั้งหมดตามปกติ)

### TC-SEARCH-09: ล้างตัวกรองทั้งหมดจากหน้าไม่พบข้อมูล [Negative]
- **Given** Member เข้าสู่ระบบ
- **And** กดคลิ๊กไปที่หน้า "สำรวจเนื้อหา"
- **Then** ระบบแสดงหน้า Empty State พร้อมข้อความ "ไม่พบโพสต์ที่ตรงกับตัวกรอง"
- **When** กดปุ่ม "ล้างตัวกรองทั้งหมด"
- **Then** ระบบทำการล้างข้อความในช่องค้นหา และยกเลิกการเลือก Checkbox ตัวกรองทั้งหมด
- **And** ระบบกลับมาแสดงรายการโพสต์ทั้งหมดตามปกติ โดยเรียงลำดับจากวันที่ล่าสุดไปเก่าสุด
